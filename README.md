# Landing Page - Frontend Skill Test

Saya membuat aplikasi web landing page dengan tampilan modern dan responsif.  
Website ini terdiri dari tiga halaman utama: Home, Product, dan About, yang semuanya memiliki navbar/headernya dan footer konsisten

## Cara Menggunakan Website

1. Home Page

   - Menampilkan hero section sebagai pengenalan aplikasi

2. Product Page

   - Menampilkan daftar produk dari [Fake Store API](https://fakestoreapi.com/products)
   - Tersedia kolom Search untuk memudahkan pencarian produk
   - Pengguna dapat menambahkan produk ke keranjang (Add to Cart) dan menghapus item jika tidak diperlukan dan jumlah barang akan terupdate di keranjang yang berada di navbar, disana user bisa melihat jumlah dan barang apa yang ditambahkan selain user bisa menghapusnya disana

3. About Page

   - Menyediakan penjelasan singkat mengenai aplikasi
   - Terdapat kontak Customer Service dengan ikon interaktif

4. Responsif di berbagai perangkat
   - pada Navbar ketika di perangkat kecil seperti smartphone navbar menu ditengah akan hilang kemudian menjadi hamburger menu
   - Website dapat digunakan dengan baik di desktop, tablet, maupun smartphone(Responsive)

## Ringkasan Fitur

- Home Page: Hero section + ringkasan fitur aplikasi
- Product Page: Daftar produk dari API, fitur pencarian, serta modal pada saat klik add to cart keranjang belanja
- About Page: Informasi singkat + kontak Customer Service
- Tampilan Konsisten: Navbar & footer sama di seluruh halaman

## Teknologi yang Digunakan

- React JS (Vite)
- TailwindCSS (styling)
- React Router (navigasi halaman)
- React Icons (ikon)
- GSAP (animasi)
- Fake Store API (data produk)
